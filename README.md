# Tontoo CoreIcon

A Rust library for making app icons and using SF Icons in UIs

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
CoreIcon = { path = "/Library/System/coreicon.library" }
```
